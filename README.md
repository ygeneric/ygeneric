---

## partially open sourced?

most of my projects are **partially open sourced**.

this usually means:
- older versions are public
- newer versions probably aren't
- some modules/features may be missing
- random build scripts are gone
- documentation may or may not exist

why?

mostly laziness.

i don't always feel like:
1. compiling the portable version
2. compiling the setup/installer version
3. cleaning the source code
4. uploading huge repos to github
5. fixing github screaming about file size limits

eventually i usually upload *something* though 👍

---

## can i decompile/equivalent your stuff?

mostly, yes.

for my fully closed-source projects:  
no.

for my **partially open sourced** projects:  
go ahead. i actually encourage it.



if you decompile/reverse something and upload it somewhere, it helps everyone:

- users get source access
- bugs get fixed faster
- i save time
- everybody wins
